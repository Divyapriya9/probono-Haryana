# Haryana Free Legal Aid - unofficial guide

A free, static web page: how to get free legal aid in Bhiwani and Haryana, plus the Pro-Bono Basis advocates named in the official
"Panel of Advocates of Haryana (SLSA, DLSAs, SDLSCs)-2026".

- Not run by, or endorsed by, NALSA, HSLSA or any DLSA.
- Data source: https://haryana.nalsa.gov.in/?p=8599 (PDF linked from there). Copyright in the source list belongs to its publisher; it is
  reproduced here as short factual entries with attribution. Remove on request.
- Compiled with AI assistance (Claude, by Anthropic); see the page footer for the exact credit.

Rebuild: edit `build_site.py`, run `python3 build_site.py`, commit and push.
